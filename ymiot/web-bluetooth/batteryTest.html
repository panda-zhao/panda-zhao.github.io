协议说明

帧格式

帧头长度(高)长度(低)长度反码(高)长度反码(低)命令字数据(N)校验
0x55LHLL~LH~LLCMDData...XOR

长度 = 长度字段(4) + 命令(1) + 数据(N) + 校验(1)；校验 = 从长度字段到数据末尾逐字节异或

指令列表

命令字名称发送数据返回数据
0x01检测夹子连接状态 无 D1: 00=成功; D2: 00=连接良好, 01=黑夹不良, 02=红夹不良
0x02模块连接状态查询 无 D1: 00=成功
0x03复位 无 D1: 00=成功
0x04读取当前电压 无 D1~D4: 电压 = D1×10+D2+D3×0.1+D4×0.01 (V)
0x05额定标准及容量设置 D1: 标准(0~9); D2~D5: 容量值(大端) D1: 00=成功
0x06电池测试结果查询 无 D1: 状态; D2: 电池状况; D3~D6: 电压; D7~D10: 冷启动电流; D11~D14: 内阻; D15~D17: SOC%; D18~D20: SOH%
0x07设置电池类型 D1: 0=普通, 1=AGM, 2=GEL, 3=EFB D1: 00=成功
0x08内阻校准 D1+D2×0x100 = 校准值(如 0x3E8=10.00mΩ) D1: 00=成功
0x09获取软件版本 无 D1: 00=成功; D2,D3: 版本号(如 0x64=100→V1.0.0)
0x0A启动系统负荷测试 D1: 00=停止, 01=开启 D1: 状态; D2: 测试状态; D3~D4: 静态电压; D5~D6: 启动电压
0x0B最大负荷系统测试 D1: 00=停止, 01=开启 D1: 状态; D2: 测试状态; D3~D4: 静态电压; D5~D6: 启动电压
0x0C充电系统测试 D1: 00=停止, 01=开启 D1: 状态; D2: 测试状态; D3~D4: 当前电压; D5~D6: 最低; D7~D8: 最高
0x0D模块状态查询 D1: 00=蓝牙芯片, 01=APP D1: 响应目标; D2: 00=成功; D3: 0=空闲, 1=测试中
0x0E设置电池电压类型 D1: 00=12V, 01=24V D1: 00=成功
0x0F获取产品信息 无 D1: 00=成功; D2~D7: 版本(6B ASCII); D8~D24: MAC(17B ASCII); 后续: 产品类型+名称+客户ID
0x10验证是否官方 8位随机数字的HEX编码(如 10 + 37313037...) D1: 00=成功; D2~D9: 8字节加密结果用于校验

电池状况对照 (0x06)

值状态
0x00电池良好 (Good)
0x01请更换电池 (Replace)
0x02电池良好，请充电 (Good-recharge)
0x03请充电后再测试 (Charge & retest)
0x04坏格电池 (Bad cell)
0x05仪表损坏 (Tester broken)

初始化流程

  1. 发送 0F — 获取产品信息（版本/MAC/型号）
  2. 发送 04 — 读取当前电压，用于判断电池规格
  3. 发送 0E00 或 0E01 — 根据电压设置电池规格（≤16V → 12V，>16V → 24V）
